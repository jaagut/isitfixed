Settings

Operating systems

Drag to set the order cases use. Selected versions are the defaults for new cases; each case can change its own selection.

Trend Micro Deep Security

Matches kernel fixes against the kernels bundled in Deep Security Agent 20 LTS and the published Kernel Support Package list. Turn this off if you do not use Deep Security: Is It Fixed then hides all TMDS details and stops loading the inventory.

TMDS support data is turned off on this server.

Severity

If a CVE has no score in this version, the next available version is shown and labelled.

Appearance

Updates & notifications

The server also re-checks your cases hourly while this tab is closed. You are told only about changes you can act on: a new status, a newly published fix or mitigation, new Trend Micro support, or a rejected CVE. Source timestamps, notes and advisory edits stay quiet.

Changed cases move to the top of the sidebar with a New marker and the changed rows are highlighted. Desktop notifications are optional and need permission (HTTPS or localhost).

Backup

Backups include cases, source snapshots and settings. Browser storage can be cleared; export a backup to keep a copy.
